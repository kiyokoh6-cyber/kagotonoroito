遊び方（OpenRouterのAPIキーの取得方法）

このアプリを利用するには、OpenRouterのAPIキーが必要です。

まず、OpenRouterの公式サイトにアクセスしてください。
「Sign In」からアカウントを作成、またはログインします。
ログイン後、API Keysのページを開き、「Create Key」から新しいAPIキーを作成します。
作成したAPIキーをコピーして、アプリのAPIキー入力欄に貼り付けてください。

APIキーは第三者に知られないよう、大切に管理してください。
クレジットは最初は少額（5ドルぐらい）からお試しください。

OpenRouter公式サイト：
OpenRouter

API Keys：
OpenRouter API Keys

※「Create Key」を押した後にエラーが出たり、いきなり「…」で隠れた詳細ページに飛ばされてしまう場合は、シークレットウィンドウ（プライベートブラウズ）で作り直してみてください。拡張機能が原因で正常にキーが表示されないことがあります。
